# Bundled font sources

The OVID Converter bundles these fonts so the interface remains consistent on clean Windows installations:

- **Google Sans Flex** — Latin letters, numbers and primary interface typography. Source: <https://fonts.google.com/specimen/Google+Sans+Flex>. License: SIL Open Font License 1.1.
- **Noto Sans SC** — Simplified Chinese glyph fallback. Source: <https://fonts.google.com/noto/specimen/Noto+Sans+SC>. License: SIL Open Font License 1.1.

The complete license is included in `OFL-1.1.txt`. Google Sans Flex does not contain the Simplified Chinese glyph set, so Noto Sans SC is deliberately configured as its fallback instead of leaving glyph selection to the operating system.
