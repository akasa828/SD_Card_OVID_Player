# 安全策略 / Security Policy

## 支持范围 / Supported versions

安全与可靠性修复优先针对 [Releases](https://github.com/akasa828/SD_Card_OVID_Player/releases) 中标记为最新稳定版的固件；prerelease 和 `main` 用于提前验证后续改动。

Security and reliability fixes target the latest stable firmware listed in [Releases](https://github.com/akasa828/SD_Card_OVID_Player/releases). Prereleases and `main` are used to validate upcoming changes.

## 报告问题 / Reporting a vulnerability

如果问题涉及可能造成设备损坏、异常写卡、越界访问或不应公开的安全细节，请不要先发布公开 Issue。请通过仓库的 **Security → Report a vulnerability** 私下提交报告，并附上受影响版本、硬件、复现步骤和影响范围。

If an issue could cause device damage, unintended SD-card writes, out-of-bounds access, or contains details that should not be public, do not open a public Issue first. Use **Security → Report a vulnerability** in this repository and include the affected version, hardware, reproduction steps, and impact.

普通播放错误、兼容性问题和 UI 缺陷可以直接使用 Bug Report 模板。

Ordinary playback errors, compatibility problems, and UI defects can use the public Bug Report template.
